# Configure Cart Value and Currency Thresholds

## V09-S01 - Choose a spending condition

Use Cart Value Rewards when the offer depends on eligible spending, not the quantity on a product line. In a new Tiered discount campaign, choose that trigger in Conditions. Our example is ten percent from fifty U.S. dollars. Enter the minimum in Rewards. A blank maximum leaves this tier without an upper spend bound; it does not set a maximum discount benefit.

## V09-S02 - Add explicit currency amounts

Open Currency-specific thresholds and add Canadian dollars. Enter seventy as the CAD minimum while keeping fifty as the USD base. These are independently chosen business amounts, not automatic exchange-rate conversion. The current form explains that unconfigured currencies do not qualify. Repeat the configuration for every currency and tier you advertise, and check any separate campaign-wide minimum overrides as well.

## V09-S03 - Read the saved values back

Review the offer, save it inactive, then reopen Rewards. Expand the currency section and check USD fifty, CAD seventy and the ten-percent rate. Closing an advanced section does not erase its values. Currency controls the amount comparison; it does not select an audience country or guarantee a shipping rate. This recording verifies persistence, not a live market switch or a new checkout test.

## V09-S04 - Test the advertised boundaries

Before launch, test one cent below, exactly at and above each threshold in the cart's actual currency. Compare eligible merchandise rather than tax, shipping or compare-at prices. Exclusions and gift-counting settings can change what qualifies. Apply the actual intended discount code and recheck totals; do not assume every discount affects qualification identically. If you add free shipping, verify delivery rates separately. Keep theme progress messages consistent with the same thresholds and restrictions.
