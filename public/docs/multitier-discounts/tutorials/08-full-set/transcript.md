# Configure a Full Set Discount on Shopify

## V08-S01 - Define a complete set

A full-set offer waits for all configured tier targets, rather than discounting any two unrelated products. In this example, Coral is the starting product and Sun is the required second product. We will configure ten percent for the trigger and twenty percent for Sun. Choose Tiered discount, name the test and use percentage rewards. Keep this as a separate draft instead of editing an existing live campaign.

## V08-S02 - Separate eligibility from the trigger reward

In Conditions, choose Products or variants and select Coral. Turn on Apply only when full set is in cart. This controls eligibility. Apply discount to trigger products is a separate decision: enable it and enter ten percent only because this example includes a reward for Coral itself. Leaving that second switch off would not give Coral its own discount. Neither switch selects Sun for you.

## V08-S03 - Set the required tier target

In Rewards, enter twenty percent for Tier Two and select Sun under Required Products for This Tier. Check the returned product card. Leaving an optional target list empty can broaden the rule, so do not skip this selection. Review the complete-set requirement, separate trigger rate and Sun reward together, then save inactive. Reopen both steps to confirm these values survived the save.

## V08-S04 - Plan complete and incomplete cart tests

This video proves the stored configuration, not a newly activated checkout calculation. Before launching, test Coral alone, Sun alone, both together and removal of either required item. With one twenty-four-dollar Coral at ten percent and one twelve-dollar Sun at twenty percent, the illustrative merchandise total is thirty-one dollars and twenty cents, before tax, shipping and other discounts. Also test repeated units and two complete sets; never infer the result from the number of visible cart rows.
