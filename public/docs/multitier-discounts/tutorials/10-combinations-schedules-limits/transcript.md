# Control Discount Combinations, Schedules and Limits

## V10-S01 - Prepare a scoped code offer

Advanced settings should express a clear offer, not replace it. This example is a code-based quantity break: two or more Coral notebooks receive ten percent. In Offer, choose Discount Code and enter a unique test code. Select only Coral in Conditions and set the two-unit reward in Rewards. We keep the campaign inactive throughout this recording, so the example cannot change a live customer's purchase.

## V10-S02 - Review both sides of combinations

In Review and launch, open Combination Settings. Product, order and shipping discounts are independent categories. This example enables all three, but Shopify must also accept the combination on the other discount. These checkboxes are not a guarantee that every coupon stacks. Test the campaign alone first, then the intended codes separately and together. Do not disable gift verification merely to hide a conflicting-code warning.

## V10-S03 - Separate timing and different limits

Check the displayed shop timezone before selecting an end date and time. It can differ from your computer's timezone. In Quantity and Sorting, zero means unlimited discounted units on each qualifying line; it is not a cart purchase limit. In Limits, enable a usage count and enter ten for this code example. A usage limit counts total redemptions, not one redemption per customer. Minimum spending and maximum discount amount are different controls.

## V10-S04 - Save and verify the whole decision

Save inactive and reopen Review and launch. Confirm the code, start and end times, three combination categories, quantity cap and usage limit. An enabled campaign can still be outside its schedule, while a saved inactive draft never becomes eligible just because its start date arrived. Before a real launch, test accepted and incompatible codes, removal and reapplication, boundary times and the final checkout quantities. This walkthrough verifies saved settings, not live redemptions or exhausted usage.
