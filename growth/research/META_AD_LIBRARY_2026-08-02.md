# Meta Ad Library Pattern Review — 2026-08-02

**Status:** Partial first observation  
**Cost:** $0  
**External actions:** None  
**Source:** Public Meta Ad Library active-ad results

## Scope

The first pass used one broad category query and one focused competitor query.
The broad query was noisy and returned unrelated Shopify education, ecommerce,
automation, and B2B products. It is not suitable as a category-performance
dataset.

The focused `Pumper Bundles` query exposed multiple active ads linked directly
to its Shopify App Store listing. Active status proves current delivery only;
it does not reveal spend, targeting, profitability, conversion, or creative
quality.

## Patterns observed

### Pumper

- Repeats a small number of core messages across multiple ad IDs and durations.
- Uses short product-oriented video, including approximately 10-second variants.
- Centers each ad on one easy-to-understand promotion mechanic, such as a free
  gift unlocked by a purchase milestone or a quantity/offer block.
- Sends the CTA directly to the Shopify App Store listing.
- Uses revenue, profit, AOV, and effortless-growth claims that MerchantCanvas
  cannot and should not repeat without its own evidence.

### Adjacent Shopify app example

- A B2B Shopify app used a very short persona-specific problem statement and a
  direct App Store CTA.
- This supports testing concise problem framing as a format, not copying its
  product language or treating it as an MTD competitor.

## Implications for MTD

1. Lead with one promotion workflow per creative rather than listing every
   feature.
2. Show real product evidence within the opening seconds.
3. Keep the CTA concrete: install from Shopify.
4. Differentiate through control and clarity: offer, eligibility, guardrails,
   storefront guidance, and checkout logic.
5. Avoid generic AOV, profit, revenue-lift, popularity, and effortless-growth
   claims.

## Original creative hypotheses

### C1 — Four-step promotion workflow

- Hook: Build the promotion rule before it reaches checkout.
- Visual: Offer → Target → Guardrails → Checkout using approved UI evidence.
- Format: 10-15 second vertical and square motion variants.
- CTA: Install MultiTier Discounts from Shopify.

### C2 — Quantity-break clarity

- Hook: Define who qualifies, what changes, and when the offer stops.
- Visual: Real campaign configuration followed by shopper-facing progress.
- Format: Short screen sequence with one annotation per step.
- CTA: Review plans or install from Shopify.

### C3 — Buy X Get Y control

- Hook: A trigger, a reward, and explicit campaign guardrails.
- Visual: Product/collection selection, reward configuration, combination
  controls, and checkout outcome.
- Format: 15-second vertical walkthrough.
- CTA: Start with the free plan.
