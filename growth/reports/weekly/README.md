# Weekly Reports

Create one report per ISO week as `YYYY-Www.md`. Each report must include:

- source freshness and missing sources;
- movement in primary KPIs, drivers, and guardrails;
- experiment status and spend against authorization;
- SEO/AEO findings based on the fixed cadence;
- decisions made, decisions deferred, and owner approvals needed;
- links to snapshots and experiment evidence.

Do not fill missing values with zero. Use `unavailable` or `not observed`.
