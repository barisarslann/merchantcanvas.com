# Owner tracking

This folder is the shared control surface for MerchantCanvas growth work.

- Open [`META_PILOT_CHECKLIST.md`](META_PILOT_CHECKLIST.md).
- Mark an owner task complete by changing `[ ]` to `[x]`.
- Do not paste card numbers, CVV codes, one-time passwords, account passwords,
  recovery codes, or other credentials into these files.
- Codex updates the agent-owned items only after verifying the corresponding
  external state.
- A checked preparation item never authorizes campaign activation. Launch has
  its own explicit owner checkbox.
